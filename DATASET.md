# Dataset

The project works with biometric signals such as ECG, PPG, accelerometer, and audio. Since this involves sensitive data (especially for children), the GitHub repository is kept **code-only**.

---

## Why data is not included
- The data is sensitive
- Data folders and file types are ignored using `.gitignore`


---

## Public reference datasets
For development and testing, public datasets can be used as references only.

- **WESAD (Wearable Stress and Affect Detection Dataset)**  
  https://www.kaggle.com/datasets/orvile/wesad-wearable-stress-affect-detection-dataset  

  Contains wearable sensor data (ECG, EDA, accelerometer) collected from adults for stress research.

- **PAMAP2 Physical Activity Monitoring Dataset**  
  https://archive.ics.uci.edu/dataset/231/pamap2+physical+activity+monitoring  

  Contains wearable sensor data for different physical activities. Useful for testing activity and motion pipelines.
